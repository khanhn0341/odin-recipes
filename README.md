Odin Recipes

A simple recipes website built as part of **The Odin Project's** Foundations Curriculum. This project demonstrates foundational knowledge of **HTML** and basic **Git/GitHub** workflows.

## 🛠️ Features & Pages
This repository contains a collection of simple recipe pages, complete with ingredients, steps, and images:
* **Lasagna** (Classic introductory page)
* **Biryani** (Aromatic rice and meat dish)
* **Roast Chicken** (Perfectly crispy whole chicken)

## 🧠 Skills Learned
Through building this project, I practiced:
* Structuring web pages using semantic HTML elements (`<h1>`, `<ul>`, `<ol>`).
* Working with relative file paths to link images and navigate between local HTML files.
* Managing a project history using Git (commits, staging, and structural refactoring).
